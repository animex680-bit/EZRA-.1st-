# DO / DON'T — Hard Rules

Quick reference. These are non-negotiable across ALL output.

---

## ALWAYS DO

| Rule | Why |
|------|-----|
| Start with dark backgrounds | Dark = premium, depth, sophistication |
| Use custom easing on every animation | Linear = mechanical = amateur |
| Intentional empty space | Breathing room is a design choice, not laziness |
| Maximum 2 typefaces per piece | More = noise, hierarchy collapses |
| Test your motion at actual delivery size | Looks different at 375px than in design |
| Teal undertone in deep shadows | Prevents dead / cheap blacks |
| Ground type in a system (scale, tracking rules) | Random sizing = accidental design |
| One clear primary message per composition | Two messages = no message |
| Reference the token files before choosing colors | Consistency is the system |
| Run the anti-slop checklist before delivery | Self-QA catches 80% of mistakes |

---

## NEVER DO

| Rule | Why |
|------|-----|
| Pure flat `#000000` as background | Dead, dimensionless, cheap |
| Linear easing in any animation | Mechanical, robotic |
| Bounce or spring in Stream A work | Wrong emotional register |
| Gradient with 5+ color stops (unless generative) | Gradient abuse = decoration, not design |
| Mix more than 2 accent colors without reason | Color chaos = confusion |
| Stock photography aesthetic | Immediately signals "not premium" |
| Drop shadows with warm/pink/yellow tones | Cheap, 2010-era web design |
| Bold serif fonts at body size | Unreadable, heavy, artless |
| All-caps body text | Caps = reduced readability |
| Overlay text that covers subject's face | Breaks the visual and the message |
| Text outside safe zones in vertical video | Gets cropped or hidden by Instagram UI |
| Pure white backgrounds for brand moments | Too ordinary — we live in the dark |
| Confetti/sparkle effects unless brand is playful | Not our aesthetic register |
| White or bright green screen-glow effects | Gaming streamer look |
| 3D pie charts | Chartjunk, distorts data |
| "Techy" fonts (Orbitron, Exo 2, etc.) | Cliché tech aesthetic |
| Neon colors without restraint | Overwhelms the composition |
| Comic Sans, Papyrus, or similar | Self-explanatory |
| Centering everything symmetrically | Lazy composition, no hierarchy |
| Adding animations just to have movement | Animation must communicate, not decorate |

---

## THE TASTE TEST

Before finishing any piece, ask:

> "Could this appear in a campaign by a brand I admire — Muji, Apple, Bottega Veneta, Linear, or Pitch?"

If the answer is NO or MAYBE — refine it until it's YES.

---

## THE SILENCE TEST

Look at the composition for 3 seconds, then look away.

> "What is the ONE thing I remember?"

If you can't answer clearly — the hierarchy is broken. Fix it.

---

## QUICK COLOR SANITY CHECK

```
Dark background?        YES or REWORK
Accent colors ≤ 2?      YES or REWORK
Text readable?          YES or REWORK
No gradient abuse?      YES or REWORK
Teal in shadows?        YES or ADD
Stream A: warm or cool accent (not blue)?  VERIFY
Stream B: blue or teal accent?             VERIFY
```

---

## QUICK MOTION SANITY CHECK

```
Every animation uses custom easing?      YES or FIX
Duration: >150ms for all animations?     YES or FIX
Duration: <2000ms for B interactions?    YES or FIX (unless atmospheric loop)
No linear easing?                         CONFIRM
No bounce in Stream A?                    CONFIRM
All elements have clear entry/exit?       YES or FIX
Motion communicates something?            YES or REMOVE
```
