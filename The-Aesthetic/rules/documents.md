# Documents — Rules
## Decks, PDFs, Proposals, Reports

---

## Stream Selection

Documents are Stream B dominated — precision, clarity, intelligence.
Stream A enters only in hero/cover moments.

**Default**: B 90% / A 10% (cover only)

---

## Pitch Deck Layout

### Slide Dimensions
- Widescreen: 1920×1080 (16:9)
- Print: A4 landscape (297×210mm)
- Square: 1440×1440 — LinkedIn / social

### Slide Grid
- Margins: 80px all sides (desktop), 60px print
- Gutter: 24px between columns
- Max columns: 2 (never 3 in a deck)

### Slide Types
```
COVER:   Full bleed image (Stream A) + company name + tagline
SECTION: Big number or single word, massive type, clean
CONTENT: 2-col: headline left, body/proof right
DATA:    Chart or stat, full-width, minimal chrome
QUOTE:   One sentence, oversized, attributed
IMAGE:   Full-bleed photograph or render, minimal text
CLOSE:   Clean, dark, single message, contact info
```

---

## Typography for Decks

```
Cover headline:   Cormorant Garamond 72–96pt, light (Stream A)
Section headline: Inter 64–96pt Bold, tracking -0.03em
Slide title:      Inter 28–36pt SemiBold, tracking -0.01em
Body:             Inter 16–20pt Regular, line-height 1.6
Caption/Source:   Inter 11pt, ALL CAPS, tracking 0.1em, muted
Stat number:      Inter 64–120pt Bold — visual anchor of slide
```

## Color for Documents

**Light version** (professional default):
```
Background: #FFFFFF or #F8F8FC (slightly blue-tinted)
Surface:    #F2F2F8
Accent:     #3B82F6 (stream_b primary)
Text:       #0C0C10
Text 2:     #6E7F8D
Border:     #E2E2EE
```

**Dark version** (premium/creative/brand):
```
Background: #0C0C10
Surface:    #141418
Accent:     Stream B accents
Text:       #F0F0F6, #9090A8
```

**Cover slide**: Always Stream A — dark BG, editorial image, serif headline.

---

## Data Visualization

**Chart colors** (stream_b accent palette):
```
Primary:  #3B82F6 (blue)
Secondary:#0EA5E9 (teal)
Tertiary: #8B5CF6 (purple)
Positive: #10B981 (emerald)
Negative: #F43F5E (rose)
Neutral:  #6E7F8D (muted)
```

**Chart rules**:
- No 3D charts
- No pie charts for more than 3 segments (use bar or donut)
- Grid lines: very light (#E2E2EE light, #2A2A35 dark)
- No chartjunk
- Always label the key insight above the chart in text

## PDF / Report Structure

```
Cover:         Full page — Stream A visual, title, date, brand
Contents:      Text-only TOC, clean numbers
Section breaks:Full page — big number + section name, dark BG
Content pages: 2-col grid: headline → body → media
Callout boxes: Glass-style card with stream_b accent border
Pull quotes:   Oversized, left-border accent, italic (Cormorant)
Data pages:    Chart + annotation, full bleed capable
Back cover:    Contact, brand mark, url
```

---

## Proposals

```
Cover page:        Full-bleed dark, serif headline, Stream A
Executive summary: Clean white/light, large intro, no clutter
The Work:          Side-by-side challenge | solution, clean grid
The Investment:    Numbers as heroes (big, centered), package tiers in cards
Next Steps:        Simple numbered list, large and clean
About:             Minimal bio, references (quality > quantity)
```

## Quality Check

- [ ] Cover could stand alone as an art piece
- [ ] No slide has more than 40 words (content max 80)
- [ ] All charts labeled with key insight in headline
- [ ] Typography follows the scale
- [ ] Colors from token file (no ad-hoc choices)
- [ ] No Lorem Ipsum
- [ ] PDF: font embedded, image resolution ≥150dpi
- [ ] Would you hand this to a Fortune 500 client without embarrassment?
