# THE AESTHETIC — Reference Mind

This is the living aesthetic reference book for all creative work across every pipeline.
Every visual decision — motion graphics, websites, apps, 3D assets, docs, social content —
must be grounded in what lives here.

## Structure

```
/AESTHETIC_MIND.md          ← Master reference. Read this first.
/streams/
  STREAM_A_THE_VOID.md      ← Fine Art / Sculptural / Editorial sub-style
  STREAM_B_THE_INTERFACE.md ← Digital Product / Tech / UI sub-style
/tokens/
  colors.json               ← Color tokens for both streams
  typography.json           ← Type systems
  motion.json               ← Animation + timing principles
  shadows.json              ← Shadow / depth specs
/rules/
  motion-graphics.md        ← Motion graphics (CapCut, After Effects, Remotion)
  websites.md               ← Web design and 3D web experiences
  apps.md                   ← App / UI design
  assets-3d.md              ← 3D models, renders, illustrations
  content-social.md         ← Instagram Reels, thumbnails, social posts
  documents.md              ← Decks, PDFs, proposals
/quick-ref/
  DO_DONT.md                ← Hard rules: what is always allowed vs. never
  STACK.md                  ← Approved tools and stacks per medium
```

## The Two Streams

Study of 72 reference images across two Drive folders ("MY aesthetics" + "my aesthetics2")
revealed **two distinct but complementary aesthetic streams**. Both live under the same roof —
one is the soul, the other is the body.

| Stream | Code Name | Energy | Domain |
|--------|-----------|--------|--------|
| A | **THE VOID** | Silent luxury, sculptural, editorial | Fine art, fashion, physical texture |
| B | **THE INTERFACE** | Precision, premium tech, intelligent | Digital product, UI/UX, web, AI |

Both streams share a common foundation: **premium minimalism, depth, and deliberate restraint.**

When in doubt, use Stream B for screen work and Stream A for emotional / brand anchor moments.
